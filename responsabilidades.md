Frente 1 — Interface gráfica
Responsabilidades:
- Desenvolver a janela principal.
- Criar o layout geral.
- Implementar o explorador lateral.
- Implementar a divisão de tela com QSplitter.
- Criar menus e barras de ferramentas.
- Desenvolver a aparência minimalista.
- Implementar os temas claro e escuro.
Entregáveis:
- Janela principal funcional.
- Layout integrado.
- Componentes visuais preparados para receber os módulos de edição e PDF.


Frente 2 — Editor de texto
Responsabilidades:
- Implementar o editor com QTextEdit.
- Desenvolver as ferramentas de formatação.
- Implementar os comandos de edição.
- Integrar o editor ao sistema de salvamento.
- Implementar indicação de alterações não salvas.
- Preparar a integração com o corretor ortográfico.
Entregáveis:
- Editor funcional.
- Formatação de texto.
- Salvamento e abertura de documentos.


Frente 3 — Gerenciamento de PDFs
Responsabilidades:
- Implementar a abertura de PDFs utilizando PyMuPDF.
- Desenvolver a renderização das páginas.
- Implementar navegação e zoom.
- Implementar seleção e grifos.
- Implementar anotações textuais.
- Implementar persistência das modificações no PDF.
Entregáveis:
- Visualizador funcional.
- Sistema de navegação.
- Sistema de anotações e grifos.


Frente 4 — Ortografia e configurações
Responsabilidades:
- Integrar CyHunspell.
- Preparar o dicionário português brasileiro.
- Implementar a identificação de palavras incorretas.
- Implementar o destaque visual.
- Disponibilizar sugestões de correção.
- Implementar gerenciamento de configurações JSON.
- Integrar as preferências aos temas e ao editor.
Entregáveis:
- Verificador ortográfico funcional.
- Configurações persistentes.
- Gerenciamento de preferências.


Frente 5 — Integração e qualidade
Responsabilidades:
- Definir a arquitetura e os contratos de comunicação.
- Criar e manter o repositório Git.
- Definir padrões de desenvolvimento.
- Integrar os módulos.
- Desenvolver testes de integração.
- Identificar e corrigir problemas.
- Configurar o PyInstaller.
- Validar a versão final do executável.
Entregáveis:
- Aplicação integrada.
- Testes executados.
- Executável funcional.
- Documentação técnica.

A quinta frente não deve ficar isolada das demais: o responsável deverá acompanhar o desenvolvimento desde o início, e não apenas receber os módulos quando estiverem prontos.
